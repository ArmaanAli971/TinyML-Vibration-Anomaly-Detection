# CWRU Dataset

Source:
Case Western Reserve University Bearing Data Center

Dataset:
12 kHz Drive-End Bearing Fault Data

Sampling frequency:
12 kHz

Channel:
Drive-End (DE)

Initial classes:
Healthy
Inner Race Fault
Ball Fault
Outer Race Fault

Initial fault diameter:
0.007 inch

Motor loads:
0, 1, 2, 3 HP

Approximate speeds:
1797, 1772, 1750, 1730 RPM

Purpose:
Public benchmark for vibration-based fault classification.

Important:
CWRU results are separate from own-hardware validation.
